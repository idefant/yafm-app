# YAFM App

## Develop

```sh
# Start in dev mode
npm run tauri dev

# Build project
npm run tauri build
```

## Android App

Рабочий тестовый вариант в ветке `develop-android`. Работает не так как хотелось бы, но работает.

Описание для разработки под Android написано в ветке `develop-android` в файле `/src/pages/ChooseFolderPage.tsx`.
